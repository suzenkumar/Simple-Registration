# 📝 Simple Registration Form (HTML & CSS)


> A clean and responsive **registration form** built using **HTML5** and **CSS3**, designed for beginners learning form structure and styling basics.

---

## 💡 Project Overview

The **Simple Registration Form** is a front-end mini project that demonstrates how to design a user-friendly form layout using **HTML** and **CSS** only.  
It includes input fields for name, email, password, gender, and more — all styled neatly with a responsive layout.

---

## ✨ Features

- 🎨 Clean and modern UI design  
- 📱 Fully responsive form layout  
- 🔒 Input fields for name, email, password, gender, and more  
- 🧭 Proper HTML structure with labels and placeholders  
- 🌐 Easy to integrate with backend or JavaScript validation later
